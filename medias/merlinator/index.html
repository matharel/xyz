Merlinator Judgement Day

Mode d’emploi

  1. Organiser la musique dans IN en renommant les fichiers pour qu’ils soient lisibles sur l’enceinte.
  2. lancer .merlinatorjudgementday playlist.bin
  3. avec Merlinator, ouvrir la playlist out/playlist.bin et l’écraser (merlinator doit faire un bidouillage)

Timéo suggère de tester sans l’étape 3 qui était peut-être juste là pour récupérer les histoires déjà sur l’enceinte.

Les images

Elles doivent avoir les caractéristiques suivantes:

  • jpg
  • 128x128

Dans un dossier, quand elles s’appellent:

  • art.jpg → elles seront utilisées pour le dossier
  • le-nom-d-un-morceau.jpg → elles seront utilisées pour ce morceau

Pour convertir les images:

magick input_image.* -resize 128x128^ -gravity center -crop 128x128+0+0 +repage art.jpg

Les morceaux

À priori doivent être sous format mp3 128ko/s. J’essayerai de mettre ici si je teste d’autres formats compatibles.

Pour les télécharger depuis Spotify, voilà ce que j’ai trouvé de plus ergonomiques:
Spotify Downloader

Spotube fonctionne aussi, mais attention au format de conversion. Et en général, je n’arrive pas à télécharger tous les morceaux.

Pour utiliser Merlinator

En utilisant python virtual environnement, je peux m’assurer d’ouvrir merlinator avec la bonne version de python et les bonnes librairies.

Dans le dossier merlinator:

source python-environnement/bin/activate
cd src
python merlinator.py
