Marks

Basic commands

Marks allow recording position to jump back to it. There are two types of marks, lowercase for the current file and uppercase: for jumping between files (only one per file).

  • mV set a mark
  • 'V jump to mark
  • ]' jump to next mark
  • [' jump to previous mark
  • d'a delete from current line to line of mark a
  • c'a change …
  • y'a yank …

If using backticks instead of quote, it respects the position in the line.

Delete marks

  • :delmarks a delete mark a
  • :delmarks a-d delete marks a, b, c, d
  • :delmarks abxy delete marks a, b, x, y
  • :delmarks aA delete marks a, A
  • :delmarks! delete all lowercase marks for the current buffer (a-z)

Special marks

Wow ! I think there are very interesting marks here :

  • `. jump to position where last change occurred in current buffer
  • `" jump to position where last exited current buffer
  • `0 jump to position in last file edited (when exited Vim)
  • `1 like `0 but the previous file (also `2 etc.)
  • '' jump back (to line in current buffer where jumped from)
  • `` jump back (to position in current buffer where jumped from)
  • `[ or `] jump to beginning/end of previously changed or yanked text
  • `< or `> jump to beginning/end of last visual selection

marks.nvim

Add other useful mappings keybindings:

I like m; for setting or removing mark, very easy.

  • m, set the next available mark
  • m; Toggle the next available mark at the current position
  • dmx Delete mark x
  • m] & m[ move to next and previous mark
  • m:x Preview mark x
