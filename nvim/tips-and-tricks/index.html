folders

  • zc: Close the fold under the cursor.
  • zo: Open the fold under the cursor.
  • za: Toggle the fold under the cursor (open if closed, close if open).
  • zA: Toggle the fold under the cursor recursively (affecting all nested folds).
  • zR: Open all folds in the file.
  • zM: Close all folds in the file.

mini-surround

À mettre en page:

If you type S(, it will be surrounded by spaces. However if you use the closing ) instead S) it will not be surrounded by spaces.

This applies of course to all bracket pair surroundings, <> [] {} (), not merely to (), although the behavior of S< is such that it expects a tag enclosure so only S> is able to surround as <>.

From the doc:

Regular mappings:

  • Saiw) - add (Sa) for inner word (iw) parenthesis ()).
  • Saiw?[[<CR>]]<CR> - add (Sa) for inner word (iw) interactive surrounding (?): [[ for left and ]] for right.
  • 2sdf - delete (Sd) second (2) surrounding function call (f).
  • Sr)tdiv<CR> - replace (Sr) surrounding parenthesis ()) with tag (t) with identifier ‘div’ (div<CR> in command line prompt).
  • Sff - find right (Sf) part of surrounding function call (f).
  • Sh} - highlight (Sh) for a brief period of time surrounding curly brackets (}).

Extended mappings (temporary force “prev”/“next” search methods):

  • Sdnf - delete (Sd) next (n) function call (f).
  • Srlf( - replace (Sd) last (l) function call (f) with padded bracket (().
  • 2sfnt - find (Sf) second (2) next (n) tag (t).
  • Shl} - highlight (Sh) last (l) second (2) curly bracket (}).

  • yaw – yank around word

  • 3yy – yank three lines starting at the current one

Répéter une commande complexe

On peut l’écrire en mode insertion. Elle est ainsi stockée dans le “dot register”. Pour la refaire un certain nombre de fois:

  • n@. – repeat n times what happened in the dot register Quand on n’utilise le “.” une seule fois, il réplique la commande à l’identique. Quand on l’utilise plusieurs fois, il l’utilise en mode normal, et donc ne basculera que en mode insertion une fois qu’il rencontrera la commande lui demandant de le faire.

Text Objects

Super ressource : Vim Text Objects: The Definitive Guide To edit efficiently in Vim, you have to edit beyond individual characters. Instead, edit by word, sentence, and paragraph. In Vim, these higher-level contexts are called text objects. Vim provides text objects for both plaintext and common programming language constructs. You can also define new text objects using Vim script. Learning these text objects can take your Vim editing to a whole new level of precision and speed.

And in the conclusion: The key is to try to always edit by text object. Editing by motions e.g., by part of a line, to the next occurrence of a character, is tedious, clumsy, and slow. Instead of correcting a misspelling character by character, change the entire word and re-type it.
