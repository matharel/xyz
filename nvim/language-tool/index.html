Language Tool

LanguageTool is an AI-based grammar checker. It can be used as a language server for NeoVim.

Ltex-ls

Ltex-ls stands for Language Tool Extension Language Server. It’s a implementation of Language Tool in a language server format. It takes the grammar and spell-checking capabilities of LanguageTool and makes them available for real-time use in text editors that support language servers (as NeoVim).

Mason

Mason is a tool that helps you easily install and manage external programs and tools that NeoVim can use, like language servers, linters, or formatters. It:

  • install the tools
  • make the setup and configuration
  • take care of the updates

Installation with Mason

Search the package with Mason inside NeoVim:

:Mason

And install it:

:MasonInstall ltex-ls

Then setup the same way as other languages. Here is the Lua lsp config and the ltex-ls config:

-- Lua LSP settings
lspconfig.lua_ls.setup({
    settings = {
        Lua = {
            diagnostics = {
                -- Get the language server to recognize the `vim` global
                globals = { "vim", "reaper" },
            },
        },
    },
})

-- Add LTeX configuration
lspconfig.ltex.setup({
    on_attach = lsp_attach,
    cmd = { "ltex-ls" },
    filetypes = { "markdown", "text" },
    flags = { debounce_text_changes = 300 },
    settings = {
        ltex = {
            language = "fr",
            additionalRules = { enablePickyRules = true },
            dictionary = {
                ["en-US"] = { "customword" }, -- Add words to dictionary
                ["fr"] = { "monmotfrançais" },
            },
        },
    }
