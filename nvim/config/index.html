Lazy

L’installation se fait dans le fichier plugin.lua. Pour avoir accès à Lazy, il faut taper:

:Lazy

Langage Server Protocol

lspconfig

:lspconfig-all

Mason

Mason est un plugin qui permet de gérer facilement l’installation et la mise à jour de divers outils externes et serveurs de langage dans Neovim.

:Mason

Ensuite, je fais une recherche dans le fichier. J’utilise les deux commandes

  • i → install
  • X → remove

Si je veux que ce soit installé automatiquement à la prochaine installation, je peux installer les outils depuis le fichier de configuration.

Treesitter

Pour installer un language:

:TSInstall markdown

Oil

It’s not a file tree, it’s a directory viewver.

Si je fais des modifications dans oil, et que je ne veux pas les valider, je peux recharger le fichier avec :e!.
