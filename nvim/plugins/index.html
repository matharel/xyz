Plugins

Oil

  • g? → help menu
  • _ → “actions.open_cwd” (Current Working Directory)
  • ~ → “actions.cd” (Change Directory)
  • <C-c> → close
  • <C-p> → preview
  • gx → “actions.open_external”
  • g. → “actions.toggle_hidden”
  • <C-g> → permet d’afficher le chemin du fichier actuel (fonctionne aussi dans oil).
  • <C-l> → to refresh, for example after creating a new file with a hugo command (file that I could create with :!hugo -s .. new content groupes/kloog/budget/index.md) from within vim in a oil page.
