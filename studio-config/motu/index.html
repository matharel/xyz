Bugs

Bruits parasites en écoutant de la musique. Quand je change le buffer size, j’ai une coupure, et le routing se change. J’ai l’impression qu’aussi, à chaque fois que je ferme où que j’ouvre reaper, ça change d’où sort “computer”. Mais ça le fait aussi tout seul.

J’ai deux manières de changer le buffer size, dans la 1248 et dans pw.

Les deux énigmes à résoudre:

  • comment configurer le buffer size
  • comment faire en sorte que ça ne saute pas de canal en canal

J’ai désactivé pipewire comme ça:

systemctl --user disable pipewire
systemctl --user disable pipewire-pulse
systemctl --user disable pipewire-media-session
systemctl --user stop pipewire.socket
systemctl --user mask pipewire.socket

Pour le reloader avant reboot :

systemctl --user unmask pipewire.socket
systemctl --user enable pipewire.socket
