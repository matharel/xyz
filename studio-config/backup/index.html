Backup

Disque dur externe

Sur un disque dur externe:

rsync -av --update reaper/terroir-collapse /mnt/backup/reaper

Cela va prendre tout le dossier terroir-collapse et le mettre dans le dossier reaper.
La deuxième fois, il vérifie si il y a des changements.
Attention la présence ou non du trailing slash est très importante.

La commande précédente est équivalente à:

rsync -av --update reaper/terroir-collapse/ /mnt/backup/reaper/terroir-collapse/

C’est un comportement de rsync. Sur le dossier source:

  • sans trailing slash: c’est le dossier qui est copié

  • avec un trailing slash: c’est le contenu du dossier qui est copié

  • a: Archive mode

  • v: verbose

  • --update: ignore existing files
