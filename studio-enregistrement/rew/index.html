REW

Calibrating the interface

Ne me semble pas super utile avec les interfaces modernes, mais permet de prendre en main le logiciel.

  • make a loop between an output and an input
  • make the measurement You can make a cal file if the measurement is not ideal.

Calibrate SPL Reading

Indispensable pour pouvoir avoir des résultats qui s’affichent de manière lisible. Il faut pour cela:

  • prendre un soundmeter (j’ai pris une appli sur mon tél)
  • ouvrir l’ongler SPL Meter
  • appuyer sur calibrate et rentrer le résultat que donne le soundmeter

Measure with a timing reference

L’intérêt immédiat pour moi, c’était de mesurer la latence que rajoute miniDSP. Voici les settings que j’ai rentré. Dans préférence:

Output:
De ce que je comprends, c’est une nomination interne à REW, dans tous les cas, il faudra que je fasse les routing dans pipewire (cf. graph suivant)

Voici les routings que j’ai fait:

Pour pouvoir faire les routings il faut que REW envoit du son en continu. Dans Preferences -> check Levels, cela permet de diffuser du son en continu pour pouvoir faire les routings dans qpwgraph.

Hardware routings:
output 1 -> enceinte de gauche
output 2 -> loopback dans entrée 2 (aux9 dans pw)
entrée 1 -> le micro de mesure
entrée 2 -> le loopback depuis output 2

En gros, la sortie gauche de Alsa va dans les sorties 1 et 2 de la fireface.
Alsa récupère à gauche le micro de mesure et à droite la loopback.

Dans l’onglet mesure probablement dit, il faut cocher l’option suivante:

Timing:
Use loopback as timing reference
