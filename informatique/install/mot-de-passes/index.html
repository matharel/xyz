Automatic Koofr mount

  1. Authenticate with Koofr
  • open Koofr web interface
  • Generate a one-time password (in settings)
  1. Configure rclone : rclone config
  2. test the remote : rclone ls koofr:
  3. test mount : rclone mount koofr: ~/koofr writes
  4. Create systemd user service and resume service

→ plus qu’à essayer la base de donnée qui est entre les deux
