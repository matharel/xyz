How to partition and format drive

create a new partition table

First we have to create a new GPT partition table

sudo parted /dev/sdX mklabel gpt

Create a new partition

Then we create a new partition covering the drive:

sudo parted /dev/sdX mkpart primary ext4 1MiB 100%
  • Start at 1MiB for alignment
  • Create a primary partition intended for ext4 file system.
  • Use 100% to cover the entire drive

create a New file system

sudo mkfs.ext4 /dev/sdX1
  • mkfs.ext4 → make file system ext4
