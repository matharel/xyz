Wifi qui ne fonctionne pas bien

[SOLVED] Boot process slowdown because of /dev/tpmrm0 start job. / Newbie Corner / Arch Linux Forums

systemctl mask dev-tpmrm0.device

Des pistes intéressantes ici: Wi-Fi Not Working in Linux? Here’s How to Fix it - Make Tech Easier

Notamment sur la carte réseau de l’ordinateur, et sur le fait de bien s’assurer qu’elle soit chargée au démarrage.

Une autre piste, c’est ce post: Boot stalls at “A start job is running for Network Name Resolution” / Kernel & Hardware / Arch Linux Forums

tridactyl

Using Search Engines by Keyword? · Issue #194 · tridactyl/tridactyl

Dans l’edit du deuxième commentaire:

:set searchurls.[name] [url]
# to enable searching with
:{,tab,win}open [name] [query]

#. E.g.
set searchurls.i https://duckduckgo.com/?t=h_&q=%s&iax=images&ia=images
:open i bonjour

set searchurls.gi https://www.google.com/search?tbm=isch&q=%s
