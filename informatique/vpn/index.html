ProtonVPN setup with WireGuard on Arch Linux

Step 1: Update the System & Reboot

Ensure your kernel and headers match before using WireGuard.

sudo pacman -Syu
reboot

After reboot, verify:

uname -r   # should match the installed linux-headers version

Step 2: Install Required Packages

sudo pacman -S wireguard-tools openresolv

wireguard-tools provides wg and wg-quick
openresolv provides resolvconf needed for DNS setup

Step 3: Get Your ProtonVPN WireGuard Configuration

  1. Go to https://account.protonvpn.com/account

  2. Under Downloads → WireGuard configuration, select:

    • Country/server (e.g., US-FREE)
    • Protocol: TCP or UDP (your preference; TCP is more stable through firewalls)
    • Tick optional options like:
      • ✅ VPN Accelerator
      • ✅ NAT-PMP (if needed)

  3. Download the .conf file (e.g., proton-US-FREE-73.conf)

Step 4: Move and Secure the Config

sudo mkdir -p /etc/wireguard
sudo mv ~/Downloads/proton-US-FREE-73.conf /etc/wireguard/proton.conf
sudo chmod 600 /etc/wireguard/proton.conf

Step 5: Start the VPN

sudo wg-quick up proton

If all goes well, you’ll see lines like:

[#] ip link add proton type wireguard
[#] wg setconf proton /dev/fd/63
[#] ip route ...
[#] nft -f /dev/fd/63

To stop the VPN:

sudo wg-quick down proton

Step 6: Verify It’s Working

1. Check your external IP

curl ifconfig.me

Run the same command before and after the VPN to confirm IP change.

2. Check DNS server

cat /etc/resolv.conf

You should see a DNS from ProtonVPN or a 10.x.x.x address.

Or test for leaks:

  • https://dnsleaktest.com
  • https://ipleak.net

3. Check tunnel status

sudo wg

Look for:

  • Interface: proton
  • Recent handshake
  • Data sent/received

4. Check routing

ip rule
ip route show table 51820

Should show a default via proton route.

Optional: Add a Killswitch

Block all traffic when the VPN is down — ask if you’d like help setting that up.
