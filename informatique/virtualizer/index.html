Installation

pacman -S qemu-desktop virt-manager dnsmasq
sudo systemctl enable libvirtd.socket
sudo usermod -a -G libvirt sebastien
sudo virsh net-autostart default
reboot

update Guest additions

Pas possible de mettre à jour virtualbox parce que conflit avec guest additions.

  1. Désinstaller les guest additions avec Pacman
  2. Mettre à jour le système (incluant virtualbox)
  3. Réinstaller les guests additions de l’AUR
  4. Démarrer la machine
  5. Menu > Devices > Upgrade Guest Additions (si pas accès au menu, voire plus loin).

UPDATE 2025/01

Pour mettre à jour, j’ai dû retirer :

sudo pacman -Rsnc virtualbox-ext-oracle virtualbox-guest-iso

View

Normalement on change les views avec la host key. Vu que je n’arrive pas à avoir cette hostkey dans virtualbox, on est obligé de le faire par le **menu de la machine virtuelle en question:

  1. soit en clic droit sur la machine puis > Settings > User Inteface > Visual Sate
  2. soit depuis la menu bar (accessible seulement en normal window) > View

Full-Screen mode

Le plus naturel. Attention quand la fenêtre sway n’est pas en fullscreen, on a pas accès â tout l’écran. Le menu de la machine virtuelle n’est pas accessible.

Normal window

Permet de juxtaposer la machine virtuelle avec des fenêtres sway. C’est le seule mode où le menu de la machine virtuelle est visible et accessible.

Me parait plus sage de rester en normal window, je viens de bien galérer à trouver le menu. J’ai retiré la status bar qui ne me paraissait pas pertinente. Pour la remettre View > Status Bar > Show Status Bar.

Add usb device

il faut que j’ai installé les paquets:

pacman -S virtualbox-guest-iso

Et j’ai installé aussi ceux-là, même si je ne suis pas vraiment sûr d’en avoir besoin pour l’usb:

rua install virtualbox-ext-oracle

Detect fireface 802

Avant les usb devices étaient détectés automatiquement. Dernièrement, il fallait que je les coches dans: Menu Bar > Devices > Usb

Si je veux avoir accès à la carte son depuis arch linux, il faut que j’éteigne la machine virtuelle windows. Ça ne suffit pas de déconnecter l’usb dans virtualbox, à partir du moment où windows démarre, je n’ai plus accès à la fireface.
