Mounting Partition

Mounting partitions without sudo

Works only with ext4.

udisksctl mount -b /dev/sdb1
umount /dev/sdb1

Check partitions usage

If I cannot mount the partition, I can check the processes that are using the mount:

sudo fuser -vm /mnt

Then I can kill the processes.
