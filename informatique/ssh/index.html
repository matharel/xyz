sshfs

This should be enough :

sshfs friend@hostname:/ ~/mnt
fusermount -u ~/mnt

This is a more complete and reliable command :

➜  ~ sshfs -o reconnect,ServerAliveInterval=15,ServerAliveCountMax=3,allow_other,default_permissions ambre@192.168.1.193:/ citron

This version adds :

  • auto-reconnect
  • keepalive a long idle connection
  • other users can see the mount
  • permission checks are sure to fully reflect remove behavior
