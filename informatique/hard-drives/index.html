Hard Drives

Tester la connexion

Port usb 2 ou 3

Le transfert était vraiment lent, et c’était à cause d’un câble qui n’était pas usb c 3.0. Voici les commandes qui m’ont permis de déterminer que ça venait du câble.

➜  ~ lsusb
Bus 006 Device 002: ID 0781:55ae SanDisk Corp. Extreme 55AE

Une fois que j’avais l’id du disque dur, je peux savoir quelle connexion j’ai avec lui:

 ➜  ~ sudo lsusb -v -d 0781:55ae | grep -i bcdUSB
   bcdUSB               3.20

Quand je n’avais pas le bon câble cette commande me donnait bcdUSB 2.10.

Gbps

Pour déterminer la vitesse de transfert, il faut aussi tester le driver.

➜  ~ lsusb -t
/:  Bus 002.Port 001: Dev 001, Class=root_hub, Driver=xhci_hcd/10p, 10000M
    |__ Port 002: Dev 002, If 0, Class=Mass Storage, Driver=uas, 5000M

Dans toute la réponse, il faut chercher la ligne qui contient Mass Storage. Ici je suis sur le port usb C qui est un peu décalé et j’ai comme résultat 5000M.

Cela correspond à des Gbps.

J’ai le même résultat avec mes deux ports usb A. Il n’y a que avec les deux ports usb C de l’arrière que j’arrive à 10000M

Correspondance entre Gbps et port usb

  • 480M → USB 2.0
  • 5000M → USB 3.0
  • 10000M → USB 3.1

En gros, c’est la commande lsusb -t qui donne le plus d’informations.
