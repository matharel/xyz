Se connecter en SSH

How to get and configure your Git and github SSH Keys

Pour se connecter en SSH il faut:

  1. avoir une clé SSH
  2. copier cette clé sur le remote

check existing key

ls -la ~/.ssh

create Key

ssh-keygen -t rsa -b 4096 -C your@email.com
ssh-add ~/.ssh/id_rsa

Copy public SSH Key

cat ~/.ssh/id_rsa.pub

Then add the public Key on github or gitlab account.

Why is Git always asking for my password ?

If Git prompts you for a username and password every time you try to interact with GitHub, you’re probably using the HTTPS clone URL for your repository.

Using an HTTPS remote URL has some advantages compared with using SSH. It’s easier to set up than SSH, and usually works through strict firewalls and proxies. However, it also prompts you to enter your GitHub credentials every time you pull or push a repository.
