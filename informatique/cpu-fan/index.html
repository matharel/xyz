Cpu Fan

cpu scaling

Installation

sudo pacman -S cpupower
sudo systemctl enable --now cpupower.service

Usage

cpupower frequency-info

→ available cpufreq governors: performance powersave schedutil

sudo cpupower frequency-set -g powersave
sudo cpupower frequency-set -d 800MHz -u 1GHz

Turbo boost

Turbo boost est là par défaut, et monte ma fréquence de cpu à 5.7GHz
Si je le désactive, ça bloque le CPU à 2.7GHz.

Connaître le status de turbo boost:

cat /sys/devices/system/cpu/intel_pstate/no_turbo
  • output 1: Turbo Boost is disabled
  • output 0: Turbo Boost is enabled

Disable

echo "1" | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo

Enable

echo "0" | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo

Create a systemd service

Je veux garder ces deux commandes :

echo "1" | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo
sudo cpupower frequency-set -g powersave

Créer ce fichier:

# /etc/systemd/system/cpu-settings.service
[Unit]
Description=CPU settings to disable Turbo Boost and set frequency scaling
After=multi-user.target

[Service]
Type=oneshot
ExecStart=/bin/sh -c "echo '1' > /sys/devices/system/cpu/intel_pstate/no_turbo"
ExecStart=/usr/bin/cpupower frequency-set -g powersave
RemainAfterExit=true

[Install]
WantedBy=multi-user.target

Activer le service:

sudo systemctl enable cpu-settings.service

Pour le tester sans rebooter:

sudo systemctl status cpu-settings.service

Pour avoir les infos et s’assurer que tout fonctionne bien:

sudo systemctl status cpu-settings.service

Fan in manual or auto mode

cat /sys/class/hwmon/hwmon4/pwm1_enable
  • 0: Fan is completely off or disabled.
  • 1: Fan is in manual mode, allowing software (e.g., ThinkFan) to control it.
  • 2: Fan is in automatic mode, and the BIOS/EC (Embedded Controller) is controlling the speed.
