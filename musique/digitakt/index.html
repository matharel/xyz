Slice

Slice will take whatever sample we have loaded on this track and apply a slice grid between the start and the end point of our sample.

Grid parameter: adjust the number of slices we have.

To play them, we use the keyboard FUNC + TRK. If we choose a KB SCALE (anything but chromatic) and KB FOLD, each number correspond to the number of the slice.

Slice. It’s either on slice, or we can select a number of slice and plays it chormatically with the keyboard.

song mode

Full Tutorial, Performance, and Thoughts

You can create a chain, and then create the song from the current chain:

  1. create a chain (by holding a pattern then another one, always keeping hold of the last one)
  2. enter song mode. Load an empty song if the current one is not.
  3. yes: create rows from chain
