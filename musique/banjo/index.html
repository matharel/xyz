Technique pour les trouver sur Thomann

Chez d’Addario pour le bronze phosporeux, il faut ajouter PB + le tirant. Pour les cordes aigus en acier, il faut ajouter PL en suffixe.

Il suffit de faire une recherche dans le moteur de thomann avec :

  • PL013
  • PL020
  • PB030
  • PB042 Et on se compose un jeu comme on veut pour 10,52€.
