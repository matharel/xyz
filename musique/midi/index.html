MIDI

aconnect

Pour connecter un controller avec son synthé:

aconnect -l
aconnect 24:0 18:0

aseqdump

Permet de lister les ports:

➜  ~ aseqdump -l                   
 Port    Client name                      Port name
  0:0    System                           Timer
  0:1    System                           Announce
 14:0    Midi Through                     Midi Through Port-0
 28:0    Xkey                             Xkey MIDI 1
129:0    Bome Network Virtual             Pitchi
129:1    Bome Network Virtual             MadameBidule
130:0    Bome Network                     Notifications

Pour écouter un port:

➜  ~ aseqdump -p 28:0
Waiting for data. Press Ctrl+C to end.
Source  Event                  Ch  Data
 28:0   Note on                 4, note 48, velocity 25
 28:0   Note off                4, note 48, velocity 0
 28:0   Note on                 4, note 50, velocity 87
 28:0   Note off                4, note 50, velocity 0
 28:0   Note on                 4, note 52, velocity 83
 28:0   Note off                4, note 52, velocity 0
 28:0   Note on                 4, note 53, velocity 127
 28:0   Note off                4, note 53, velocity 0

Pour filter les informations (par exemple quand il y a du realtime qui vient tout polluer):

➜  ~ aseqdump -p 129:0 | grep -E "Note"

129:0   Note off                0, note 54, velocity 0
129:0   Note on                 0, note 54, velocity 127
129:0   Note off                0, note 54, velocity 0

Bomebox & Reaper

Si les bomebox sont visible sur le réseau et détecter par network, on peut les voir grâce à aseqdump.

Par contre Reaper ne les vois pas. Pour que Reaper les voit, il faut créer un module MIDI virtuel avec la commande suivante:

sudo modprobe snd-virmidi

Ensuite, l’on s’assure que le module virtuel a bien été créé.

➜  ~ aseqdump -l
 Port    Client name                      Port name
  0:0    System                           Timer
  0:1    System                           Announce
 14:0    Midi Through                     Midi Through Port-0
 28:0    Xkey                             Xkey MIDI 1
 32:0    Virtual Raw MIDI 4-0             VirMIDI 4-0
 33:0    Virtual Raw MIDI 4-1             VirMIDI 4-1
 34:0    Virtual Raw MIDI 4-2             VirMIDI 4-2
 35:0    Virtual Raw MIDI 4-3             VirMIDI 4-3
129:0    Bome Network Virtual             Pitchi
129:1    Bome Network Virtual             MadameBidule
130:0    Bome Network                     Notifications

Ensuite je dois connecter Pitchi à ce nouveau module:

aconnect 129:0 32:0

Il faut noter que seul le port 32:0 fonctionne dans Reaper.

La connection que nous venons de faire peut aussi se faire de manière graphique, et dans tous les cas nous la voyons apparaitre dans qpwgraph:

Dans reaper, il faut que je me rendre dans Preferences → Audio → MIDI Inputs: → hw:VirMIDI → Enable.

À présent je suis connecté à la bomebox.

Ensuite il faut router les infos midi depuis pitchi vers mon ordinateur cerise. Pour l’instant je n’ai réussi à ne router que l’accordéon, directement depuis l’entrée BomeBox DIN, sans que le message midi soit affecté par les scripts.

Pour cela, il faut ajouter la route MIDI suivante: Source: BomeBox DIN → Destination: cerise
