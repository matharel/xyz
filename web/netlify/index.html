Add a domain name

  • choose the website on the netlify page
  • in the left menu domain management

En face du nom de domaine, il y a un menu déroulant options avec:

Go to DNS panel

Ici, ils proposent de pointer les domain's name servers sur netlify. En gros, chez le domaine provider (ici ovh), il faut rentrer les 4 dns servers suivants:

  • dns1.p09.nsone.net
  • dns2.p09.nsone.net
  • dns3.p09.nsone.net
  • dns4.p09.nsone.net

UPDATE: Les noms de serveurs varient à chaque fois. Pour savoir exactement les dns qu’il faut entrer, il faut:

site configuration → Domain management → add domain → options → Set up Netlify DNS
