Maninuper des données

À trier

  • depuis un template, j’ai l’impression qu’il suffit de .Param "myVar" pour récupérer une variable de front matter
  • depuis un shortcode, il semblerait qu’il faille préciser .Page.Param "myVar". Je ne sais pas pourquoi …

Cette page est principalement une traduction de cette excellente ressource:
Hugo and Data: The Basics | The New Dynamic

Variables

Initialiser une variable:

{{ $gent := "John" }}

Assigner une nouvelle valeur:

{{ $gent = "John Lennon" }}

Loops

Il n’y a qu’une sorte de boucle en moteur de template Go, c’est range:

{{ range $beatles }}
  This member is {{ . }}
{{ end }}

Conditions

Il n’y a que if et if else, tout le reste, ce sont des fonctions de comparaisons.

Comparing functions

{{ if eq $gent "John" }}
  Alors il chante.
{{ else if eq $gent "Paul" }}
  Il fait de la basse
{{ else }}
  Not sure !
{{ end }}

eq (equal) est une fonction qui prend un nombre infini de paramètres. Elle compare le premier avec chacun des suivants.

{{ eq 1 1 }} → true
{{ eq 1 2 }} → false

{{ eq 1 1 1 }} → true
{{ eq 1 1 2 }} → true
{{ eq 1 2 1 }} → true
{{ eq 1 2 2 }} → false

Voici une liste des fonctions de comparaisons:

nefirst parameter is Not Equal to second parameter!=

{{ if and (in $gent "John") (in $gent "Lennon") }}
  That must be John Lennon.
{{ end }}

With

{{ with $gent }}
  {{ . }} is the gent.
{{ else }}
  We have no gent.
{{ end }}

with évalue une fonction ou une variable. Si l’évaluation est positive, le code à l’intérieur de with est exécuté. Peut prendre un else pour exécuter un autre code en cas d’échec.

Strings

Pour concatener des variables de type string en hugo, il faut utiliser la fonction print:

{{ print $gent " was a famous song writer for " $band }}

printf est une fonction qui prend un nombre illimité de paramètres. Le premier est un string qui inclue des verbes, les paramètres suivants sont des variables dont les valeurs vont remplacer les verbes.

{{ printf "% was a famous song writer." $gent }}

Je viens de voir qu’on pouvait aussi utiliser add pour concaténer des strings:

{{ add "hu" "go" }} → hugo

Numbers

Pour faire des opérations sur les nombres, on utilise des fonctions:

{{ add 12 3 2 }} → 17
{{ mul 12 3 2 }} → 72
{{ div 12 3 2 }} → 2
{{ sub 12 3 2 }} → 7

Voici toutes les fonctions mathématiques disponibles:
Math functions | Hugo

Slices

La suite de ces notes viennent de cette page:

(Hugo and Data: Advance manipulation with Slices and Maps | The New Dynamic)[https://www.thenewdynamic.com/article/hugo-data/manipulation-slices-and-maps/]

Les slices sont des collections (objets de type liste). Ils peuvent être composés de strings, maps, Pages, etc …

Créer une Slice

{{ $gents := slice "John" "Paul" }}

{{ range $gents }}
  I love {{ . }}
{{ end }}

→ I love John I love Paul

Ajouter un élément → append

On utilise la fonction append qui prend deux arguments:

  1. le premier est ce qu’on ajoute
  2. le deuxième est la slice d’origine
{{ $gents = append "Ringo" $gents }}

En français, on ajoute “Ringo” aux gens.

On peut utiliser pipe constructs:

{{ $gents = $gents | append "Ringo" }}

On peut ajouter plusieurs entrées au tableau:

{{ $gents = append (slice "Ringo" "Georges") $gents }}

Si on veut ajouter au début de la collection, il suffit d’inverser les deux paramètres. Attention, cette fois, on ne peut pas simplement insérer un string, il doit déjà être transformé en slice:

{{ $s := slice "b" "c" }}
{{ $s = append $s (slice "a") }}

On peut lire ça comme on ajoute $s à “a”.

Supprimer les doublons → uniq

{{ $gents = uniq $gents }}

Index

Pour récupérer l’index dans une collection, il faut le stocker avec la valeur à chaque itération du tableau

{{ $gents := slice "John" "Paul" "Ringo" "George" }}
{{ range $index, $gent := $gents }}
  {{ $gent }} is at index {{ $index }}
{{ end }}

$index est juste un nom convénient pour la variable, ça peut être n’importe quel nom.

First, Last

{{ $firts_two := first 2 $gents }}

{{ $last_three := last 3 $gents }}

Assez lisible ! Attention ces fonctions retournent toujours une collection, même s’il n’y a qu’un seul élément dedans.

Les autres positions

Pour trouver un élément qui est à la troisième position, on utilise la fonction index:

{{ $s := slice "a" "b" "c" "d" }}
{{ $third := index $gents 2 }}
{{ $third }}

Affiche:

→ c

Maps

Les maps sont des tableaux associatifs, avec des paires clé/valeur.

Créer une map → dict

{{ $gent := dict
  "firstname" "John"
  "lastname" "Lennon"
}}

{{ $gent.firstname }} → "John"
{{ $gent.lastname }} → "Lennon"

Ajouter à map → merge

La fonction merge prend 2 paramètres:

  1. la map existante
  2. la nouvelle map avec ses propres paires de clé/valeur.
{{ $gent = merge $gent (dict "birth" "1940") }}

Naviguer dans la map → range

{{ range $key, $value := $gent }}
  {{ $key }}: {{ $value }}
{{ end }}

birth: 1940
firstname: John
lastname: Lennon

L’ordre est réorganisé par Go par les clés. Par contre slice respecte l’ordre utilisé à la création.

On peut rajouter un array dans la map:

{{ $gent = merge $gent (dict
  "instruments" (slice
    "Piano"
    "Guitar"
    "Vocals"
  )
) }}

La fonction range du dessus va imprimer:

birth: 1940
firstname: John
instruments: [Piano Guitar Vocals]
lastname: Lennon

Concatènation

{{ range $key, $value := $gent }}
{{ $key }}:
  {{ if reflect.IsSlice $value }}
    {{ delimit $value ", " }}
  {{ else }}
    {{ $value }}
  {{ end }}
{{ end }}

birth: 1940
firstname: John
instruments: Piano, Guitar, Vocals
lastname: Lennon

delimit concatène les valeurs de slice, et nous avons deux fonctions pour tester le type de valeur:

  • reflect.IsSlice
  • reflect.IsMap

Index

index est une fonction qui retourne la valeur associée avec une clé donnée.

{{ $gent := dict
  "firstname" "John"
  "lastname" "Lennon"
}}

{{ range slice "firstname" "lastname" }}
  {{ . }}: {{ index $gent . }}<br>
{{ end }}

firstname: John
lastname: Lennon
