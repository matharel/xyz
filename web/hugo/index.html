Notes en vrac à ranger

j’utilise {{ define }} pour faire des sortes de fonction. Ça a l’air de marcher, par contre bien faire attention que ce ne soit pas dans un autre define.

Dans un template, si on met du contenu juste avant la balise {{ define }}, ce contenu est affiché et l’intérieur de la balise est ignoré. Par contre on peut mettre un autre {{ define }} que l’on appelle depuis ce fichier là. Attention, les variables définies en dehors du bloc define seront elles aussi ignorées.

Quand j’appelle un objet:

  • {{ page }}
  • {{ site }}

ça me renvoit juste le nom de l’objet. Si je veux le contenu, il faut que je le print ou assimilé:

{{ page | debug.Dump }}
{{ site | debug.Dump }}

The LinkTitle method returns the linkTitle field as defined in front matter, falling back to the value returned by the Title method.

Surcharger une variable de config depuis le frontmatter

Alors découvert complètement par hasard, donc à vérifier avec rigueur.

<!-- baseof.html -->

{{ if .Param "TOC" }}
  <!-- content -->
{{ end }}

# params.toml
TOC = true

# hugo.toml
[params]
  TOC = true

# content/index.md
+++
TOC = true
+++
