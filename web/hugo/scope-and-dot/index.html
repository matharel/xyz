Hugo, the scope, the context and the dot

The context is stored in the dot {{ . }} and we’re using the properties of this object like so:

  • .Title
  • .Permalink
  • .IsHome

The Page dot.

The root context available in the layouts will always be the Page context. Everything you need to build this page is inthat dot:

  • .Title
  • .Permalink
  • .Resources

Even the site’s informations is stored in the Page context with .Site ready for the taking.

But in Go Template **the minute you step into a function you lose that contxt as your precious dot or context is replace bythe function’s own dot.

with

{{ with .Title }}
  {{/* Here the dot is now .Title */}}
  <h1>{{ . }}</h1>
{{ end }}

Inside with, we’ve lost the page context. The context, the dot, is now the title of the page.

Range

{{ range .Data.Pages }}
	{{/* Here the dot is that one page 'at cursor'. */}} 
	{{ .Permalink }}
{{ end }}

{{ range .Resources.Match "gallery/*" }}
	{{/* Here the dot is that one image. */}} 
	{{ .Permalink }}
{{ end }}

{{ range (slice "Hello" "Bonjour" "Gutten Tag") }}
	{{/* Here the dot is that one string. */}} 
	{{ . }}
{{ end }}

The top level context $

Hugo stores the root context of a template file in a $.

{{/* 1. Dot is the top level (list) page */}} 
<h1>{{ .Title }}</h1>
{{ range .Data.Pages }}
	<article>
		{{/* 2. Dot is the page at cursor */}} 
		<h3>{{ .Title }}</h3>
		<hr>
		{{ range .Resources.Match "images/.*" }}
			<figure>
				{{/* 3. Dot is that Resource */}}
				<img src="{{ .Permalink }}">
				{{/* $ is the top level page */}}
				<caption>{{ .Title }} from  post {{ $.Title }}</caption>
			</figure>		
		{{ end }}
	</article>
{{ end }}

Partials

Partials don’t pass any context, but it takes one parameter for that. This object will be available within the partial and be referred the dot.

Here we pass the page context (if we’re not insede a range or a with, or another partial) :

{{ partial "page/head" . }}

We can use the dict function to pass an object as parameter. dict create an associative array :

{{ partial "img" (dict "path" $path "alt" "Nice blue sky") }}

<figure class="Figure Figure--framed">
	<img src="{{ .path }}" alt="{{ .alt }}">
</figure>

With the keys lowercase (.path and .alt) we can identify easier the custom context.

Top level $ from partial

If we want to have the page context within the partial, we need to add it to the dict:

{{ partial "img" (dict "Page" . "path" $path "caption" "Nice blue sky") }}

<figure class="Figure Figure--framed">
	<img src="{{ .path }}" alt="{{ .alt }} from {{ .Page.Title }}">
</figure>
