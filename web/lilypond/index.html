Lilypond

Snippet

Pour insérer des bouts de partitions lilypond dans une page web:

  1. créer un fichier lily/ma-partoche.ly
  2. l’exporter avec la commande lilypond -dbackend=svg -dcrop ma-partoche.ly
  3. l’insérer dans le fichier markdown ![Ma partoche](ma-partoche.ly)
