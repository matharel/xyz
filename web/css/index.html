7-1 pattern

While layouts can use other components to make up its contents, a component is more elemental. For example, your form should be classified as a layout block: layout is a vital function of the block, and it uses other blocks, such as buttons. But the button itself is a component because it doesn’t need any other components to fulfill its function

Organisation et convention

Il faudrait que je réunifie mon système de couleur pour que ce soit facile de le modifier dans le ficier de variable. Il faut que je trouve une convention consistance. Dans cet article OKLCH en CSS, des palettes de couleurs accessibles et cohérentes, il propose la notion de “design tokens” (valeurs atomiques de design):

$brand-accent:      /**/;
$brand-background:  /**/;
$success-accent:    /**/;
$success-background:/**/;
$warning-accent:    /**/;
$warning-bakcground:/**/;
$error-accent:      /**/;
$error-background:  /**/;

et si je continue la logique:

$link-fr:     /**/;
$link-bg:     /**/;
$headings-fr: /**/;
$headings-bg: /**/;
$h1-fr:       /**/;
$h1-bg:       /**/;
$h2-fr:       /**/;
$h2-bg:       /**/;

L’idée qui me vient à l’esprit, c’est d’aller du plus générique au plus spécifique. Par exemple:

@mixin headings($h1-fr: null) {
  @if ($h1-fr) {
    h1 {
color: $h1-fr;
    }
  } @else {
    h1 {
color: $headings-fr;
    }
  }
}

Code inspiré de ce post stackoverflow.

C’est plus verbeux à mettre en place, mais ça me permettrait vraiment de gérer la palette de couleur qui serait dans un seul fichier abstracts/_colors.scss, la classe !

Tips and tricks

Sélectionner un élément qui n’est pas l’enfant d’un élément spécifique

:not(). Mais attention, il y a plein d’effets pervers avec ce pseudo-element. Voici comment il a fonctionné pour moi:

code:not(div.highlight code) {
  // style ici
}

En français, je veux styler un bloc code qui n’est pas dans un div.highlight.

Sélectionner un élément en fonction de sa descendance

Bien pratique quand ce n’est pas possible de baliser le contenu comme je veux. Par exemple si je veux sélectionner le p parent d’une img:

p:has(img) {
}
