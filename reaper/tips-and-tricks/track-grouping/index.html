Track Grouping

Set track grouping

For example, for arming:

  • Select the track you want to group.
  • Option: Set track grouping parameters
  • tick record arm lead / record arm follow

Si je veux travailler sur plusieurs pistes en même temps, j’ouvre le track group manager:

  1. je sélectionne mes pistes
  2. je double-click dans la colonne track list avec le groupe qui m’intéresse
  3. ça ouvre la fenêtre “track grouping” et je peux y mettre mes options.

Track group manager

C’est une bonne interface, me parait plus claire que grouping matrix.

Dessus, je peux facilement (en double-cliquant sur “track list”):

  • sélectionner les pistes d’un groupe
  • ajouter à un groupe les pistes sélectionner
  • renommer un groupe
  • ouvrir le dialogue “set track grouping” correspondant à un groupe en cliquant sur les attributs.

Shift → disables any track grouping.

Comment ajouter ou retire des pistes à un groupe

  • ouvrir le track group manager
  • sélectionner des pistes
  • double cliquer dans la ligne du goupe qui nous intéresse et dans la colonne track group. Un sous-menu s’ouvre qui nous propose:
    • group only selected tracks
    • add selected tracks to group
    • remove selected tracks from group
