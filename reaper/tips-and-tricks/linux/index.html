Reaper sous Linux

Openbox

La configuration se situe ici:

~/.config/openbox/rc.xml

Pour recharger la configuration après modification:

openbox --reconfigure

J’ai retirer tous les raccourcis qui utilisaient la touche Alt pour être bien sûr qu’elle soit disponible avec Reaper.

J’ai gardé quelques raccourcis intéressants que j’ai bougé sur la touche windows:

  • W-Right → move windows
  • W-Left → resize windows
