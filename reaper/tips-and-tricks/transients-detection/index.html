Transients Detection

transient

The Transient Detection Settings windows let us defines settings for detecting transients.

I alse defined 2 shortcuts to change the treshold without opening this window:

  • Alt+- : Transient detection treshold: Decrease
  • Alt++ : Transient detection treshold: Increase

Then we can use transients to do several things.

Navigate through transients

  • tab : move cursor to next transient
  • S-tab : move cursor to previous transient

Generate transient guides

Those guides can help us to snap items on the grid if necessary. Stretch Marker - Transient Guides in REAPER - YouTube
